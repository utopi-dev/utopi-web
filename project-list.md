# Company Projects

## 1. Distributed Data Center

Sharing heat and building resilient compute networks where it makes sense.

This project works with the Quebec government to plan and implement mini data centers in residential and other buildings, such that small data center rooms can heat water and buildings. It also works with fibre optic providers, creating a densely criss-crossed, resilient compute network that maximizes efficiency. The added labour from distributing the data center is more than made up by the addition of compute.

## 2. utopi-keys

Multi-point hardware authentication protocol, using a security key design and a secure keyboard. This is a more secure input implementation. Built in Quebec.

The security keys, like YubiKey, work with the keyboard and the device. No key, no keyboard. Different keyboard, no way.

Part of the securing Quebec networking project, which will help all regions. Building a protocol, chipset, security key, and keyboard for secure environments.

## 3. utopi-eyes

A security toolset to improve OSX. A set of scripts and reports that inform a user as to what is doing what. Works on top of existing security applications.

## 4. Captains-log

Agentic logging platform to log app development, network security, and agent reports.

## 5. event-bbs

An event management and ticketing platform that implements timed content that doesn't stay forever. Temporal content. Node based. Community based. Designed for a group to run on a server and handle extreme ticket volumes easily. Minimalist. Experimental. Growing event management tools.

## 6. utopi-forensics

Secure, audited, event-based data workflows.

## 7. tbk.quebec

Support arts cooperatives and get them land and performance spaces. Reclaim the wastes, clean up polluted areas and convert into performance grounds and nature spaces. Putting performance halls and gathering spaces in the hands of arts cooperatives in Quebec, so that people are organizing local events and creating micro economies around the sites that the spaces that they own.

Each hall: Built for acoustics, to not bother neighbours, to host loud art, circus, martial arts, and other kinds of community events. Safe, sound, reasonable, all night long once a month.
